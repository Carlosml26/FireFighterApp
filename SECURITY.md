# Security policy

## Supported code

Only `v2/` is under active development. The files in `serverDB/` and
`signalServer/` are an unsupported historical prototype and must not be
deployed or exposed to a network.

## Reporting

Please use GitHub's private vulnerability reporting for this repository rather
than a public issue. Do not include real incident, personnel, vehicle-location,
credential, or device data in a report.

## Operational warning

V2 is currently a local reference slice, not an approved emergency-services
system. Keep established dispatch and radio procedures authoritative until a
formally governed security, privacy, reliability, usability, and field pilot is
complete.
